# Flight-Ticket-Management-System
Features :
-Interactive Session Loop: Starts/exits the system with a confirmation prompt and processes multiple customers sequentially.
-Customer Information Capture: Collects the customer's Name, Email, and Phone Number.
-Flight & Cabin Selection: Chooses between One-way or Round-trip journeys, 3 destinations (Japan, Singapore, USA), and 3 cabin classes (Economy, Business, First).
-Date Validation: Verifies strict DD/MM/YYYY date formats for departure and return dates.
-Passenger & Base Pricing: Inputs adult and child counts, calculating child tickets at a 25% discount off adult rates.
-Multi-Tier Discount System: Automatically applies:
  -15% destination discount for Japan.
  -15% membership discount.
  -10% promo code discount (CheapFlight).
  -5% tier discount for totals reaching or exceeding RM 6,700.
-Tax & Financial Processing: Calculates net totals, adds a 6% Sales and Services Tax (SST), and computes the final payable amount.
-Receipt Generation: Prints an itemized summary of charges, discounts, tax, and final amount for each booking.
-Daily Analytics & Reporting: Tracks daily revenue collection, destination popularity, and outputs a final report identifying the "Famous" (most booked) and "Infamous" (least booked) destinations when exiting.
